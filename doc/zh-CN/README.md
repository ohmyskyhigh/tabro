## 权威

### 中文文档是帮助阅读的翻译层，英文知识库仍是唯一规范来源

规范性阅读顺序为英文的 [`TOP-DOWN-MOC.md`](../TOP-DOWN-MOC.md)：Product → User Experience → User Interface → System → Components → Files。中文资料不改变 MCP Schema、产品边界、恢复规则或组件责任。若翻译与英文规范冲突，以英文规范为准，并应修复翻译。
