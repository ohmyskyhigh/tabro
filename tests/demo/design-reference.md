# Demo page reference

## Direction

### The fixture uses a neutral work list with explicit identity and task state

Refero live style and screen searches returned `NO_SUBSCRIPTION` on 2026-09-27. The fallback references are the bundled Refero Typography Guide (neutral work-product typography, 16px base, 1.55 line height) and Craft Details Guide (visible keyboard focus and labelled form fields). The approved task brief supplies the login → choose earliest due task → note → complete → summary sequence.

The reference lock is a white canvas, dark text, restrained gray separators, system sans-serif and a single-column task list. Account identity appears above task controls. Blue is reserved for primary actions and focus; green text labels completion. No illustrations, marketing sections, dashboard or decorative cards are needed. Inputs keep native semantics and all asynchronous results have readable text states. Rendered browser inspection is required before acceptance.
