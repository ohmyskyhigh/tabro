Profile alias: creating…

The pairing code is saved in this browser profile and persists across browser windows and restarts. Use two 3-8 letter words separated by a hyphen; the lowercase words become the endpoint alias. The code identifies this installation and is not a password.

A new installation generates a code and registers automatically. Saving a different code changes the existing endpoint alias only after the broker authenticates this profile.

Normal Chrome and AdsPower both use the native companion. Direct WebSocket is retained only for explicit diagnostics.
